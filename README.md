# Luma-мод для Digma Luma

Мод встраивается в штатную программу читалки Digma Luma (EB63TFL). Всё настраивается в ней же, книги остаются fb2.
Программа не переписывается: рядом кладётся модуль `libluma.so`, который подгружается при запуске (LD_PRELOAD) и перехватывает нужные функции.

## Что даёт

**Текст**
- Свои межстрочные интервалы вместо 1.0 / 1.5 / 2.0, например 1.15 / 1.3 / 1.5. В меню видны настоящие значения.
- Свои шесть значений полей.
- Множитель размера шрифта.
- Бесполезные слоты шрифтов без кириллицы заменяются своими TTF с настоящим курсивом и жирным.
- Красная строка, отступы абзацев и выравнивание.
- Шрифт, размер, интервал и поля одни на все книги: поменял в одной — так во всех, в том числе в старых.

**Подсветка**
- Верхний ползунок — яркость, нижний — температура, у нижнего своя иконка-термометр.
- Мод пишет регистры ШИМ напрямую на 4 кГц. Минимум получается в несколько раз тусклее штатного, дальше яркость растёт по экспоненте до заводского максимума.
- Температура меняется целыми тактами ШИМ, ровными шагами по доле света, без скачков.

**Библиотека**
- Вместо имени файла — автор, серия и название из книги. Строка подбирается по настоящей ширине шрифта, порядок всегда «автор, серия, название»:
  - «Толстой Л. Н. — (Серия 3) Война и мир»;
  - не влезает — «Фамилия/(Серия 3) Назв»;
  - серия длинная — «Фамилия/(3) Назв».
- На плитках главного экрана — «Назв/Фамилия».
- Сортировка «Название» идёт по настоящему названию. Сортировка «Автор» — по фамилии, один автор — одна строка, внутри книги по серии и номеру.
- Миниатюры обложек мод рисует сам из обложки в книге. Штатные бывают сняты с экрана недорисованными. Для книг, которые ещё не открывали, миниатюры рисуются заранее.
- Заголовок в читалке — название книги вместо обрезанного имени файла.

**Остальное**
- Экран сна: обложка открытой книги целиком, под ней автор полностью, название и серия. Свою заставку из «Изображений» мод не трогает.
- Кнопки: верхние боковые листают вперёд, нижние назад. Две любые кнопки держать 3 секунды — раскладка переключается обратно.
- Процент заряда у часов, процент прочитанного у номера страницы.

Все настройки — в файле `luma/luma.ini` в памяти книги. Шаблон с комментариями — [luma/luma.ini](luma/luma.ini).
Правишь файл и перезапускаешь книгу.

## Защита

- Если программа с модом трижды подряд падает в первые 30 секунд, она запускается без мода до перезагрузки. Журнал — `luma/crash.log`.
- Пустой файл `luma/disable` в памяти книги выключает мод полностью.
- Мод рассчитан на сборку программы от 26.06.2026 и проверяет, что патчит именно то, что ожидает.
- Возврат к заводской прошивке — официальный `update.img` тем же способом.

## Как поставить

Нужны Мак или Linux, кабель, `adb`, [zig](https://ziglang.org) (сборка модуля под ARM) и `squashfs` (`brew install squashfs zig`).

Штатно ADB на книге выключен, а режим загрузчика кнопками не включается. Поэтому всё ставится штатным обновлением.

1. Скачать официальный `update.img` сборки 26.06.2026 с сайта Digma.
2. Собрать модуль: `./luma/build.sh`.
3. Собрать прошивку: `python3 build_firmware.py update.img out/update-luma.img`. Пакет повторяет официальный побайтно, кроме системного раздела `rootfs`; в нём включён ADB. Разделы с книгами и с настройками программы (`oem`) из пакета убраны, так что после установки всё остаётся на месте.
4. Положить `out/update-luma.img` в корень памяти книги под именем `update.img` и запустить обновление в настройках.

Только ADB, без мода: `python3 build_firmware.py --adb-only update.img out/update-adb.img`.

### Живой тест без перепрошивки

Когда ADB уже есть, мод можно запустить из памяти книги. Перезагрузка возвращает всё как было.

- `./luma.sh backup` — снять все системные разделы на компьютер со сверкой MD5.
- `./luma.sh test-mod` — подготовить мод (книга в режиме флешки).
- `./luma.sh live` — запустить программу с модом, не отключая кабель.
- `./luma.sh restart` — перезапустить программу после замены модуля или настроек.
- `./luma.sh log` — журнал мода.

## Файлы

- `luma/libluma.c` — модуль, `luma/build.sh` — его сборка.
- `luma/luma.ini` — шаблон настроек с комментариями.
- `luma/daemon-mod.sh` — вставки в штатный запускатель: загрузка модуля и защита от падений. Сам запускатель берётся из официальной прошивки.
- `luma/icons/` — иконка-термометр (формат LVGL 9), `luma/mkicon.py` её рисует.
- `build_firmware.py` — собирает прошивку из официального `update.img`.
- `luma.sh`, `luma/test-run.sh` — бэкап, живой тест и журнал по ADB.
- `fonts/` — PT Serif, Literata, Montserrat, Tenor Sans под лицензией SIL OFL 1.1 (тексты лицензий рядом).
- `fb2epub.py` — старый способ: fb2 → EPUB со своим оформлением, без мода.

В репозитории нет файлов Digma: ни прошивки, ни программы, ни бэкапов. Всё, что нужно, берётся из официального `update.img`.

Код мода — под лицензией MIT ([LICENSE](LICENSE)), шрифты — под SIL OFL 1.1.
