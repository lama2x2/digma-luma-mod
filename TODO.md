# Список дел Luma-мода

Всё отмеченное работает в живом режиме (`./luma.sh test-mod` + `./luma.sh live`) и пропадает после перезагрузки книги, пока не собрана постоянная прошивка.

## Сделано

- **Батарея и прогресс.** Процент заряда у часов (на главном экране — после даты, «+» при зарядке); в читалке «5/816 · 1%».
- **Заголовок в читалке** — название книги вместо обрезанного имени файла.
- **Значения в меню интервалов** — у пунктов «Маленький / Большой / Очень большой» видно число.
- **Фамилии вида «Пелевин Виктор»** в одном поле fb2 раскладываются правильно.
- **Плитки главного экрана:** «Назв/Фамилия» — название не шире половины, без точек и пробелов, по реальной ширине шрифта.
- **Список библиотеки:** строго «автор, серия, название»:
  1. «Фамилия И. О. — (Серия N) Название»;
  2. не влезает — с одной фамилией;
  3. дальше «Фамилия/(Серия N) Назв» — фамилия и серия целиком, название режется;
  4. серия длинная — «Фамилия/(N) Назв».
- **Подсветка** (закрыто, «фиксируем прибыль»):
  - верхний ползунок — яркость, нижний — температура;
  - позиция 1 — 2 такта ШИМ при 4 кГц, ниже штатного минимума; дальше по экспоненте до заводского максимума;
  - температура только целыми тактами, ползунок задаёт долю света 0…100% с поправкой на растяжку импульса (`pulse_floor = 6`);
  - у нижнего ползунка своя иконка-термометр (`luma/icons/icon_temperature_32.bin`).

## Батч 3 (сделано и проверено)

1. **Кнопки.** Верхние боковые листают вперёд, нижние назад. Две любые кнопки держать разом 3 с — переключить раскладку (запоминается в `luma/buttons.state`). Проверено.
2. **Общие настройки текста.** Шрифт, размер, интервал и поля одни на все книги: меняешь в любой — применяется ко всем (`luma/text.state`). Проверено.
3. **Экран сна.** При открытии книги мод рисует `/oem/luma_sleep.pgm`: обложка целиком, под ней автор полностью (Имя Отчество Фамилия), название и серия; ссылка `/oem/sleep.pgm` переводится на него. Свою заставку из «Изображений» не трогает. JPEG — libturbojpeg, PNG — libpng16, текст — FreeType (NotoSans).

## Батч 4

1. **Обрезанные обложки в меню — сделано и проверено.** Программа сохраняла миниатюру с экрана, пока обложка ещё дорисовывалась (0 → ~20% → ~60% → 100%). Мод перехватывает `lodepng_encode_file` и рисует миниатюру 180×240 сам из обложки в книге; один раз пересоздал старые, а для книг, которые ещё не открывали, рисует при запуске и как только видит новую книгу (`[library] thumbnails`).
2. **Сортировка — сделано.** «Автор» — по фамилии из книги, один автор — одна строка, внутри по серии и номеру (проверено, «да кайф»). «Название» — по настоящему названию, ещё не проверено глазами.
3. **Переносы — отменено.** Проверили: MuPDF мягкие переносы рисует, но решили оставить выравнивание по ширине без переносов.
4. **Перерисовка строк списка при листании** — исправлено, ждёт проверки. Программа задаёт текст строки, пока у неё шрифт темы (уже), а настоящий ставит потом. Мод меряет строку шрифтом списка: перехватывает установку шрифта (`lv_obj_set_style_text_font`, `lv_obj_add_style`) и пересчитывает строку до отрисовки. Кеш строки помнит, каким шрифтом посчитан.

## Финал

1. **Постоянная прошивка — собрана, не установлена:** `out/update-luma.img` (июньская сборка + мод + ADB, шрифты с лицензиями, иконка). В шаблоне `debug = 1`, журнал ограничен 512 КБ (старый уходит в `luma.old.log`).
2. **Репозиторий на GitHub — подготовлен локально:** новый README, `.gitignore` (бэкап, прошивки, сборка, журналы), лицензии OFL в `fonts/`. Запускатель Digma больше не лежит в репозитории: `build_firmware.py` вписывает `luma/daemon-mod.sh` в штатный. Осталось: лицензия своего кода, ссылка на официальный `update.img`, `git init` и публикация.

## Пока не понятно

- **Поля.** Как три пункта меню полей соответствуют шести значениям в таблице. Таблица в программе по адресу 0xb0e310, прямых ссылок на неё в коде не нашлось — проще проверить на экране.
- **USB.** Связь иногда рвётся из-за разболтанного OTG-переходника (не из-за питания): программа останавливается, диск уходит на Мак. Перед каждым шагом проверять, у кого диск.
